# 🛍️ LocalList: AI Listing Generator for Etsy & eBay

A lightweight, locally hosted web application that generates SEO-optimized, highly engaging product listings for e-commerce platforms like Etsy and eBay. 

Built as a submission for the **Hacktoberfest Open-Source AI Challenge (Week 2: Side Hustle)**, this project demonstrates the power of open-weight models by providing small business owners with professional AI copywriting at zero recurring cost and with absolute data privacy.

## ✨ Features
* **Zero Subscription Costs:** Runs entirely locally using open-weight models, eliminating the need for expensive API tokens.
* **100% Data Privacy:** Your unreleased product ideas, proprietary designs, and business data never leave your machine.
* **SEO-Optimized Output:** Tailors descriptions specifically for Etsy or eBay search algorithms.
* **Clean UI:** Powered by Streamlit for a fast, intuitive, and distraction-free workflow.

## 🛠️ Tech Stack
* **Frontend:** Python, Streamlit
* **Local Inference:** Ollama
* **LLM:** Llama 3 (8B)
* **API Integration:** Python `requests` module
